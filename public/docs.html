Jasmine API

POST /graphql. Supply Authorization: Bearer <key> and x-project-id when configured.

mutation($id: String!, $payload: JSON) {
  executeWorkflow(workflowId: $id, payload: $payload) {
    status requestId result error { code message nodeId retryable }
  }
}

Use mode: async to get a requestId immediately, then query checkStatus(requestId: ...). cancelWorkflow stops a pending run. runTrace exposes redacted events; runHistory lists retained runs.

Workflow lifecycle

Save writes a local draft. Deploy validates and activates an immutable version. Test deploys and executes the current draft. Invalid deployment leaves the last valid version active.

Studio JSON exports contain nodes and edges. References use {{nodeId.output.path}}. Jasmine preserves node policies in data.engineLogic and explicit condition mapping in edge.branch.

Supported nodes

Chat, API and webhook triggers; Generate Text; Structured Output; API Call; Code; Variables; Conditions; For Loop; Chat and API Responses.

Workspace persistence

JASMINE_DATA_DIR selects the local data directory. Drafts and each flow’s most recently deployed definition survive restart. Run logs and older rollback versions are retained in memory for the current server session.
